# b8g-production-rack

A **113.6 KB** self-contained Linux (`x86_64` & `ARM64`) high-performance compute runtime for your own servers or rented bare metal — keep **70%** of your verified server-bill savings.

## Highlights
- **1-Line Linux Install:** `curl -fsSL https://b8g.app/install.sh | sh` (zero Docker, zero vendor lock-in).
- **Local Telemetry + Pull-on-View Viewer:** Telemetry stays on your server; stream live only when viewing, or generate a 1-time Savings Report.
- **30-Day Renewable Lease & Zero-Lock-In Data Export:** Even on expiry or revocation, read-only data extraction to S3, SSH, or local download remains open.

## Quick Start
```bash
node --test b8g-app.test.mts
node server.mts
```
